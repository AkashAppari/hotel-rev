# Hotel Revenue SQL Project

This project contains SQL queries and a Power BI dashboard for hotel revenue analysis.

## Contents
- `SQLQuery1.sql`: Main SQL queries for data analysis.
- `DATA/`: Folder for data files (CSV, Excel, etc.).
- `dashboard/Hotel_rev.pbix`: Power BI dashboard file.
- `dashboard/PBIDesktop_5LnUynVYEy.png`: Screenshot of the Power BI dashboard.

## Usage
1. Use the SQL queries in your preferred SQL environment.
2. Open the `dashboard/Hotel_rev.pbix` file in Power BI Desktop to view or modify the dashboard.
3. Refer to `dashboard/PBIDesktop_5LnUynVYEy.png` for a quick preview of the dashboard.
